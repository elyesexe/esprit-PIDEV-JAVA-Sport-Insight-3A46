🔍 FONCTIONNALITÉS DE RECHERCHE

SPONSORS:
  • Recherche par nom        → "Apple" trouve "Apple Inc"
  • Recherche par email      → "apple.com" trouve "contact@apple.com"
  • Recherche par téléphone  → "+336" trouve "+33612345678"
  • Recherche par adresse    → "California" trouve les sponsors en Californie

CONTRATS:
  • Recherche par description    → "football" trouve les contrats football
  • Recherche par statut         → "ACTIVE" trouve les contrats actifs
  • Recherche par statut paiement → "PAID" trouve les payés
  • Filtrage par Sponsor ID      → Voir tous les contrats d'un sponsor

📊 STRUCTURE DE DONNÉES

SPONSOR:
  ├─ id (Integer) - Auto-généré
  ├─ nom (String) - Nom du sponsor
  ├─ email (String) - Email unique
  ├─ telephone (String) - Téléphone
  ├─ budget (Double) - Budget du sponsor
  ├─ logoName (String) - Nom du fichier logo
  ├─ updatedAt (LocalDateTime) - Dernière mise à jour
  └─ adresse (String) - Adresse du sponsor

CONTRAT_SPONSOR:
  ├─ id (Integer) - Auto-généré
  ├─ dateDebut (LocalDate) - Date de début
  ├─ dateFin (LocalDate) - Date de fin
  ├─ montant (Double) - Montant du contrat
  ├─ description (String) - Description
  ├─ statut (String) - Statut du contrat
  ├─ notified (Boolean) - Si notification envoyée
  ├─ statutPaiement (String) - Statut du paiement
  ├─ sponsorId (Integer) - Clé étrangère vers Sponsor
  └─ equipeId (Integer) - Clé étrangère vers Équipe

🎮 UTILISATION RAPIDE

COMPILATION:
  $ compile.bat
  ou
  $ javac -d target/classes -cp "...jar" src/main/java/tn/esprit/*/*.java

EXÉCUTION:
  $ run.bat
  ou
  $ java -cp "target/classes;...jar" tn.esprit.mains.Main

WORKFLOW TYPIQUE:
  1. Démarrer l'application
  2. Menu principal → Choisir (1 ou 2 ou 0)
  3. Sélectionner l'opération souhaitée
  4. Entrer les données demandées
  5. Voir le résultat ou l'erreur
  6. Retour au menu
